# Editing the locked spec
- The spec is locked (Baseline v1.0). Edit only to correct or to resolve an open item, and add a DEC row to `01-decisions/01-decision-log.md`.
- Never renumber or reuse REQ/BR/US/DEC/OI IDs. Keep (ref) vs (ours) provenance and Given/When/Then criteria.
- A business rule (BR) is a constraint that always holds; a requirement (REQ) is a capability. Do not mix them in one line.
