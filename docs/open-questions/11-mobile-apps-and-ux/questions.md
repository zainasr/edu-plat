# 11 Mobile apps and UX

1. (BLOCKER) Are Student, Parent and Teacher separate apps, one app with role-based experience, or PWA/web first? Which is better for distribution, updates and low-end Android devices?
2. Platforms: Android first, iOS also in 1.0? Minimum OS versions and device RAM targets? App size budget?
3. Offline behaviour per app (what is cached, what can be written offline, sync indicators, conflict rules)?
4. Parent app home screen: which 5-6 things matter most (child switcher, today attendance, dues + pay, diary, results, announcements, ID card)? Priorities and order.
5. Student app: what do they see and do (timetable, diary/homework, results, ID card QR, resources, improvement hints, behaviour appreciation)? Anything gamified in 1.0?
6. Teacher app home: what are the top 5 daily tasks (mark attendance, diary, marks entry, timetable, leave, chats)?
7. Admin web: dashboard design principle (a "today / needs action" board per role). Who should land where after login?
8. Receptionist/front-desk experience: fast fee collection, enquiry entry, student search, print receipts. Any hardware (thermal printer, barcode/QR scanner, tablet)?
9. Design system: brand colors/logo/typography undecided? Component library approach? Accessibility target (large text, contrast, simple icons)?
10. Language: English only UI confirmed; does the app need RTL support for Urdu text content (diary, messages)?
11. Onboarding in-app: first-run checklists, tooltips, sample data, short videos?
12. White-labelling: can a school have its own app name/logo (branded app) or just logo inside our app? Branded app store listings are costly - needed?
13. Notifications UX: deep links, grouping per child, badges.
14. Printing: A4/A5/thermal PDF generation for receipts, challans, ID cards, report cards — print-ready quality and speed?
15. Web responsiveness: is admin web used on phones/tablets by owners (responsive web required)?
16. Accessibility and low literacy: voice, icons, simple wording? Any need for parents who cannot read English?
