# 04 Admission and student lifecycle

1. (BLOCKER) Full lifecycle states: Enquiry -> Applied -> Test/Interview -> Offered -> Admitted -> Active -> Promoted/Held back -> Transferred out/Withdrawn/Struck off -> Graduated -> Alumni. Which states are in 1.0?
2. Admission forms: public link form (like reference) plus walk-in entry by receptionist. Which fields are mandatory vs optional? Do we need entry test/interview scheduling and scoring?
3. Admission fees and documents: which fee heads at admission (admission, registration, security, first month)? Required documents list (B-Form, previous result, leaving certificate, photos) per class?
4. Enquiry follow-up (CRM-lite): lead status, follow-up reminders, source tracking (walk-in, Facebook, referral). In 1.0 or later?
5. Student record fields: confirm the complete list (identity, B-Form/CNIC, guardian details, emergency contact, medical info/allergies, transport needs, previous school, siblings, religion/nationality, blood group, photo). Which are mandatory?
6. Duplicate detection: how do we detect the same student/family twice (B-Form, name+DOB+father mobile)?
7. Promotion: rules (all pass -> next class; by result; manual override), hold back, "promote with dues" allowed? How to treat the last class (graduate)?
8. Demote/reassign: why does reference have "demote"? Do we need section change, class correction, shift change as separate operations with history?
9. Transfer in/out and withdrawal: required fields (reason, date, dues clearance, leaving certificate/SLC number), what documents get generated, what happens to attendance/fees/behaviour data?
10. Student status effects: which statuses block attendance, fee generation, app login?
11. Sibling logic: automatic family linking by guardian mobile; sibling discount rules (2nd child x%, 3rd child y%)? Who can merge or split families?
12. Documents generated: admission form PDF, ID card, bonafide/character certificate, leaving certificate, fee certificate. Which in 1.0? Need templates editable per school?
13. Alumni: keep for later reporting only, or a full alumni portal later?
14. Student photo capture and face enrolment (links to section 05): consent and storage rules?
