# 11 ID Cards
Routes: /admin/id-card-templates, /admin/students/id-cards, /admin/staff/id-cards. Screenshots: screenshots/11-id-cards/.
- **Card Templates**: saved layouts and colour themes; tiles by kind (Smart = modern layouts, Classic = legacy, Custom = designed in-house). Template card shows live preview with sample student: school name/address, photo placeholder, name, class-section, reg no, session, admission date, signature line, **QR code**. Orientation (e.g. Smart Card Landscape), usable for students and staff. New template / Edit / Delete.
- **Student ID Cards**: choose saved template, class, section; live card preview; select students (checkbox list); Download PDF (print-ready batch). Staff ID cards mirror this.
- The QR code is the hook for scan-based attendance (see 12).
- Gaps/ideas: no card status tracking (printed/issued/lost/reissue), no digital ID in student/parent app, no NFC/barcode options, no bulk "print all school" with bleed marks. Our digital ID card shown to a camera ties directly to our attendance requirement; also library/transport use.
