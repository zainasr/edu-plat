# 04 Class Tests
Route: /admin/class-tests. Screenshots: screenshots/04-class-tests/.
- Read-only monitoring page for tests that **teachers create and mark in the mobile app** (admin does not create). Tiles: tests, marks published, awaiting marks. Filters: status (Scheduled, Marks published, Cancelled), search by title.
- Lifecycle: Scheduled -> Marks published (or Cancelled).
- Demo account: empty state ("Tests appear here when teachers create them in the app").
- Implies teacher mobile app owns day-to-day academic data entry. Idea: lightweight class test with question-level marks feeding the improvement engine.
